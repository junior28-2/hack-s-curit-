# LabPentestIA

Application Android de laboratoire pour l'apprentissage et la validation de contrôles de sécurité mobile.

## Statut

Prototype de recherche volontairement vulnérable. **Pas destiné à la production ni à un usage public.**

## Périmètre autorisé

Les tests doivent être réalisés uniquement sur :

- un émulateur ou un appareil de test appartenant à l'équipe ;
- un serveur de laboratoire explicitement autorisé ;
- des données synthétiques ;
- un réseau isolé ou un périmètre couvert par une autorisation écrite.

## Données de recherche

Aucune télémétrie n'est activée par défaut. Toute collecte doit obtenir un consentement explicite, être limitée au protocole approuvé et exclure les secrets, le contenu des communications et les identifiants persistants. Voir [RESEARCH_DATA_POLICY.md](RESEARCH_DATA_POLICY.md).

## Distribution

Distribuer l'APK uniquement via un dépôt privé ou un espace interne avec liste d'accès. Vérifier l'identité des destinataires, le hash de l'artefact et la date d'expiration de la campagne de test.

## Signalement

Documenter les résultats sans publier de secrets ou de données personnelles. Signaler immédiatement toute exposition accidentelle et supprimer les artefacts concernés.
